# 🧮 Modern React Calculator

A modern, responsive, and fully functional calculator application built using **React.js**. This project supports basic arithmetic operations, keyboard input, real-time calculations, and a premium modern user interface.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input (0–9)
* 🔘 Decimal point support
* 🧹 Clear calculator
* ⌫ Backspace/Delete functionality
* 🟰 Calculate results
* ⌨️ Keyboard support
* ⚡ Real-time calculation
* 🚫 Division by zero handling
* 📱 Fully responsive design
* 🎨 Modern premium UI
* ✨ Smooth hover and click animations

---

## ⌨️ Keyboard Support

| Key         | Action                |
| ----------- | --------------------- |
| `0-9`       | Enter Numbers         |
| `+`         | Addition              |
| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `Enter`     | Calculate Result      |
| `Backspace` | Delete Last Character |
| `Escape`    | Clear Calculator      |
| `.`         | Decimal Point         |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/react-calculator.git
```

Go to the project directory:

```bash
cd react-calculator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 🎯 Usage

1. Click the number buttons to enter values.
2. Select an arithmetic operator.
3. Enter another number.
4. Press `=` or `Enter` to calculate the result.
5. Use `AC` to clear the calculator.
6. Use `⌫` or `Backspace` to delete the last character.
